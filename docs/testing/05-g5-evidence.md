كل سباق يُطلق بطلبين متوازيين من جلستين مختلفتين عبر `RunspacePool` مع حاجز زمني واحد (`StartAt`)، ويُكرّر **3 مرات** لكل معرّف.

| C4 — TC-170 | نفس مفتاح Idempotency في طلبين متوازيين | `UNIQUE(user_id, endpoint, key)` + حالة `IN_PROGRESS` + `UNIQUE(payments.idempotency_key)` | دفعة واحدة (201)، الآخر 409 `IDEMPOTENCY_IN_PROGRESS`، صف دفع واحد وصف مفتاح واحد |

## 9. إعادة إنتاج الدليل

```powershell
# 1) تأكد من MySQL 3307 وGlassFish
Invoke-WebRequest http://localhost:8080/api/v1/health -UseBasicParsing

# 2) طبّق الترحيلات (V007..V009) والبذر إن لزم
ant -f db/build.xml db-migrate
ant -f db/build.xml db-seed

# 3) أعد تشغيل مجموعة المرحلة 5
powershell -NoProfile -ExecutionPolicy Bypass -File tools\test-phase5.ps1

# 4) حماية G4 — أعد تشغيل انحدار المرحلة 4
powershell -NoProfile -ExecutionPolicy Bypass -File tools\test-phase4.ps1

# 5) بناء ونشر
ant -f smart-hospital-ear/build.xml full
asadmin --user admin --passwordfile C:\glassfish7\userpass.txt deploy --force=true --name=smart-hospital smart-hospital-ear\dist\smart-hospital.ear
```

**ملاحظات تشغيلية:**
- السكربت أحادي البايت (ASCII) بقصد، لأن PowerShell 5.1 يقرأ ملفات `-File` بترميز ANSI.
- السكربت ينشئ أدوارًا مؤقتة (`QA_BILLING_CLERK`, `QA_COUNT_CLERK`) ومستخدمي QA، وأصنافًا ومستودعات وموردين ببادئة `QA`، وفواتير ومدفوعات تجريبية.
