### Phase 1 — التأسيس التقني والبناء (أسبوعان)

**الهدف:** EAR فارغ لكن **حقيقي** يعمل على GlassFish مع قاعدة ومخطط وHealth وواجهة هيكلية.

| المحور | المهام | المخرج |
|---|---|---|
| Java/Ant | مشاريع NetBeans: `smart-hospital-ear`, `-ejb`, `-war`؛ بناء Ant ناجح | EAR قابل للنشر |
| Jakarta EE | `jakarta.*` فقط، `persistence.xml`, JTA DataSource JNDI | حقن EntityManager يعمل |
| MySQL | إنشاء DB، مستخدم تطبيق بأقل صلاحية، `V001`–`V010` أساسية | مخطط نظيف |
| Migrations | Runner بسيط بإصدارات `VNNN__desc.sql` + جدول `schema_version` | ترقية/تراجع موثّق |
| Seed | أدوار، صلاحيات، إعدادات، خدمات أساسية، `S001`–`S005` | بيانات مرجعية قابلة للتكرار |
| Outbox | جدول `outbox_event` + كاتب داخل المعاملة (بلا Dispatcher بعد) | لا فقد حدث لاحقًا |
| Observability | Trace ID Filter، JSON logs، `/health` (DB + Disk) | تشخيص أولي |
| React | Vite + TS + Router + i18n + RTL + Design Tokens + Build إلى WAR | شاشة هيكل تعمل |
| CI | `ant clean build test` + `npm ci && npm run build` | بناء متكرر |
| Config | `hospital.properties` خارج EAR، أسرار خارج Git | لا أسرار في الكود |

**بوابة G1 — ✅ مجتازة (2026-11-12):**
- [x] `ant clean build` ينجح من الصفر — تحقق فعلي: `ant -f smart-hospital-ear/build.xml clean` ثم `ear`؛ المخرجات في `smart-hospital-ejb/dist` و`smart-hospital-war/dist` و`smart-hospital-ear/dist` (بعد إصلاح تسرّب خصائص `<ant>` بـ `inheritall="false"`).

## 8. إدارة النطاق والطوارئ

### 8.1 triggers قصّ النطاق

| الحالة | الإجراء | ما لا يُمسّ |
|---|---|---|
| تأخر P4 > 20% | تأجيل BCMA/EWS وINV الكامل إلى v1.1 | FEFO، أقفال السرير، التدقيق |
| تأخر P5 > 15% | تأجيل جرد/شراء كامل، الإبقاء على استلام/صرف | Idempotency، منع السالب |
| تأخر P7 > 20% | تقليص KPI إلى 24، التوقعات إلى طريقتين، DR إلى 4 | حد العينة، الاعتماد البشري |
| ضغط P9 | لا ميزات جديدة؛ إصلاحات فقط | الأمن، التزامن، النسخ |
| غياب عضو | مالك احتياطي + تقليل التوازي | البوابات |

### 8.2 ما لا يُقصّ أبدًا

- IAM والصلاحيات والنطاق.
- Audit hash chain.
- Idempotency للمدفوعات والصرف.
- FEFO ومنع الرصيد السالب.
- أقفال السرير والفاتورة.
- النسخ الاحتياطي والاستعادة.
- منع التنفيذ الآلي للقرارات.
