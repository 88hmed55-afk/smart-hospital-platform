```
  → صرف الدواء FEFO (WF-10)
  → فاتورة + دفع (WF-12/13)
  → تقرير مالي + KPI
```

هذا السيناريو هو **TC-E2E-001**، وأي فشل فيه يعني أن النظام غير مكتمل حتى لو نجحت كل الوحدات منفردة.
